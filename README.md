# Lakbay Kasaysayan AI — Flutter Edition

**Lakbay Kasaysayan AI** is a Flutter/Dart Filipino history tutor designed for desktop, mobile, tablet, and web. The interface combines an animated Filipino history guide, Tagalog-first conversation, microphone input, and a server-generated Filipino voice.

## Character and animation

The current guide asset is located at:

`assets/images/lakbay_lolo.svg`

The Flutter character layer includes subtle breathing, sway, blinking, thinking, and speaking states. The speaking state is synchronized to actual audio playback. A future Rive/Live2D rig can replace the current vector layer without changing the overall conversation flow.

## Natural Filipino voice

The app does **not** fall back to browser `speechSynthesis` for tutor answers. Tutor speech is generated by the Supabase Edge Function in:

`supabase/functions/lakbay-tts/index.ts`

The Edge Function calls Azure Speech server-side so the Azure key is never exposed in Flutter or in the public repository. The default voice is:

`fil-PH-AngeloNeural`

The current SSML uses a warm, conversational Filipino delivery with slightly slower pacing. The previously supplied reference recording is used only as a style/prosody target; it is not used to clone the speaker.

### 1. Configure Supabase secrets

From a terminal where the Supabase CLI is installed and linked to your project:

```bash
supabase secrets set AZURE_SPEECH_KEY=YOUR_AZURE_SPEECH_KEY
supabase secrets set AZURE_SPEECH_REGION=YOUR_AZURE_REGION
supabase secrets set AZURE_FILIPINO_VOICE=fil-PH-AngeloNeural
```

Only the first two are required. `AZURE_FILIPINO_VOICE` is optional.

### 2. Deploy the speech function

```bash
supabase functions deploy lakbay-tts
```

`supabase/config.toml` is already configured with `verify_jwt = false` for this public classroom TTS endpoint. Do not place provider secrets inside the Flutter app or commit them to GitHub.

### 3. Run Flutter with the TTS URL

Replace `YOUR_PROJECT_REF` with your Supabase project reference:

```bash
flutter run -d chrome --dart-define=LAKBAY_TTS_BASE_URL=https://YOUR_PROJECT_REF.supabase.co/functions/v1
```

For Windows desktop:

```bash
flutter run -d windows --dart-define=LAKBAY_TTS_BASE_URL=https://YOUR_PROJECT_REF.supabase.co/functions/v1
```

The built-in history answers remain available even when a live chat backend is not configured. Natural speech can therefore work independently from the future AI/history backend.

## Optional live AI/history backend

The app also accepts a separate chat backend URL:

```bash
--dart-define=LAKBAY_CHAT_BASE_URL=https://YOUR_PROJECT_REF.supabase.co/functions/v1
```

If `LAKBAY_CHAT_BASE_URL` is omitted, the project continues using its built-in demo history answers. If `LAKBAY_TTS_BASE_URL` is supplied, those answers are still spoken using the natural Filipino speech service.

## Run locally

After cloning or pulling the repository:

```bash
flutter create .
flutter pub get
```

For Chrome without external Flutter web resources when needed:

```bash
flutter run -d chrome --no-web-resources-cdn --dart-define=LAKBAY_TTS_BASE_URL=https://YOUR_PROJECT_REF.supabase.co/functions/v1
```

If your Flutter version does not support `--no-web-resources-cdn`, omit that flag.

## Voice behavior in the app

When `LAKBAY_TTS_BASE_URL` is configured:

- Every Lakbay Kasaysayan AI answer is spoken automatically.
- The old-man character enters its speaking animation while audio is playing.
- The top-right badge changes to **Natural Filipino**.
- The user can mute/unmute voice from the badge.
- The character card includes a button for replaying the welcome greeting.

When voice is not configured, the app now shows a clear **Voice setup** status instead of silently producing no audio.

## Important security note

Never add `AZURE_SPEECH_KEY` or any other private API key to Dart files, GitHub commits, `--dart-define`, JavaScript, or a public `.env` file. Only the public Supabase Functions URL belongs in the Flutter runtime configuration.
